# Developer Portfolio V1

> Personal developer portfolio and technical showcase featuring projects and skills.

## Overview

A multi-page developer portfolio and technical resume website built with Next.js and TypeScript, presenting full-stack projects, hackathon achievements, and contact details.

## Key Features

- Featured projects gallery with technology tags and architecture summaries
- Interactive skills matrix and professional milestone timeline
- Clean modern typography and layout optimized for all viewports
- Integrated contact form with input validation

## Architecture and Technology Stack

- **Core Technologies:** Next.js, React, TypeScript, Tailwind CSS, Lucide React
- **Author:** Yusra Saleem
- **Portfolio:** [yusrasaleem.dev](https://yusrasaleem.dev)

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/portfolio-v1.git
cd portfolio-v1
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
